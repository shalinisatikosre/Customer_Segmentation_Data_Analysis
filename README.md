# Customer_Segmentation_Data_Analysis

## Project Overview

This project analyzes customer purchasing behavior using Python and Power BI. The objective is to understand customer demographics, income, spending patterns, and preferred product categories through interactive dashboards.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI

## Dataset Features

- Customer ID
- Age
- Gender
- Income
- Membership Years
- Spending Score
- Preferred Category
- Purchase Frequency
- Last Purchase Amount
